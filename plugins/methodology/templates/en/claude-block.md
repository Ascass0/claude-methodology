## Methodology

This repository follows **claude-methodology**. The configuration is in `.claude/methodology.toml`; the principles are loaded when each session starts.

- Documentation: `{{DOCS}}/` · Specs: `{{SPECS}}/` · ADRs: `{{ADR}}/<category>/`
- Changelog fragments: `{{CHANGES}}/` · Changelog: `{{CHANGELOG}}`
- All work starts from a spec and goes through the `mth-*` skills. Shared history is never rewritten.
