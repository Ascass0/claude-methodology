## Metodología

Este repositorio sigue **claude-methodology**. La configuración está en `.claude/methodology.toml`; los principios se cargan al iniciar cada sesión.

- Documentación: `{{DOCS}}/` · Specs: `{{SPECS}}/` · ADRs: `{{ADR}}/<categoría>/`
- Fragmentos de changelog: `{{CHANGES}}/` · Changelog: `{{CHANGELOG}}`
- Todo el trabajo parte de una spec y pasa por las skills `mth-*`. Nunca se reescribe historia compartida.
